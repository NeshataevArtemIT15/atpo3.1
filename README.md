# Автоматизация тестирования с помощью Selenium и Python

Репозиторий с решениями практических заданий курса по автоматизации тестирования на Python с использованием Selenium WebDriver.

## О курсе

Курс посвящён основам автоматизации веб-тестирования: настройке окружения, поиску элементов на странице, работе с формами, ожиданиям и JavaScript-скриптам.

## Стек технологий

- **Python 3**
- **Selenium WebDriver**
- **ChromeDriver** (для управления браузером Google Chrome)
- **Git / GitHub** — для хранения и версионирования кода

## Содержимое репозитория

| Файл | Описание |
|------|----------|
| `lesson6_step4.py` | Заполнение простой формы с помощью разных стратегий поиска элементов |
| `lesson6_step5.py` | Поиск ссылки по тексту, вычисленному по формуле, и заполнение формы |
| `lesson6_step6.py` | Заполнение формы с 100 обязательными полями через `find_elements` |
| `lesson6_step7.py` | Поиск кнопки Submit через XPath |
| `lesson2_1_step7.py` | Решение капчи со значением `x`, спрятанным в атрибуте картинки |
| `lesson2_2_step3.py` | Работа с выпадающим списком (`Select`) |
| `lesson2_2_step8.py` | Прокрутка страницы через `execute_script` |
| `lesson2_3_step4.py` | Загрузка файла через `send_keys` |
| `lesson3_step6.py` | Переключение между вкладками браузера |
| `lesson4_step8.py` | Явные ожидания с `WebDriverWait` и `expected_conditions` |
